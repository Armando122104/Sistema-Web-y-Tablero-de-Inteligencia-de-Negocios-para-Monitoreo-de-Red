# Sistema-Web-y-Tablero-de-Inteligencia-de-Negocios-para-Monitoreo-de-Red
Implementar un sistema de monitoreo y análisis de infraestructura de red que integre una base de datos relacional, un tablero en Power BI y una plataforma web divivida por perfil de usuario, para auditar el consumo de ancho de banda y priorizar la sustitución de equipos informáticos críticos en un plazo de tres meses.
